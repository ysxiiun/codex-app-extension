# 新版环境信息 PIP 右栏避让修复

## Task Summary

- Goal: 修复 ChatGPT 更新后，宽屏正文、输入区与 Markdown 宽块重新伸入右侧“环境信息”面板下方的问题，并在面板关闭后释放预留宽度。
- Scope: 在既有 persistent rail shell 内识别新版 `thread-summary-panel` 透明 PIP 占位，修正纵向交集合同与 rail 子树几何重算，补 fixture，统一 PageRuntime revision 15，并同步 README 与 ABSTRACT。
- Result: 同一节点同时声明 `data-pip-home-surface="thread-summary-panel"` 与 `data-pip-obstacle="thread-summary-panel"` 时，wide-layout 以稳定 rail shell 左边界约束内容；普通 painted component 继续沿用原布局参考矩形合同。Release 版本已构建、签名、原子安装并启动，当前 ChatGPT 展开态实时门禁证明无重叠。
- Key Constraints: 不读取对话正文、草稿、Cookie 或 payload；不自动点击或重启 ChatGPT；不把 menu、listbox、dialog 或任意右侧浮层纳入布局；不提交或推送 Git。

## Compatibility and Troubleshooting Decisions

- 新版右栏的稳定 shell 仍存在，但实际展开状态由透明 PIP obstacle 表达；只依赖背景、边框或阴影的 painted-only 判定会漏掉该占位。
- PIP 快路径必须同时满足：位于既有稳定 rail shell 内、同一节点具有两个精确的 `thread-summary-panel` 属性、可见链成立、尺寸有效、与 rail 水平相交。单属性和宽泛右侧几何不能作为兼容 fallback。
- 精确 PIP obstacle 的纵向有效性应相对稳定 rail shell 判断；普通 painted component 仍相对 `layoutReferenceRect` 判断。当前宿主可能把底部 composer host 选为 reference rect，若所有组件都套用该矩形，顶部 PIP obstacle 会被误排除。
- rail 子树属性变化与动画必须标记一次有界几何 dirty，绕过 ordinary identity 快路径，完整 reconcile 后清除；这样展开时能及时避让，关闭动画结束后也不会遗留空白或 offset。
- PageRuntime 资源合同统一提升到 revision 15，确保已注册的旧 revision 14 adapter 被正式安装版本替换。
